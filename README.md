# 海琛（Hydrogen）

Hydrogen[/'haɪdrədʒən/]，中文名叫“海琛”。

海琛的目标并不是成为一款像 Python、Java 等等一样的工业级编程语言，而是提供一种较为基础、简单的编程语言框架，使任何《编译原理》的初学者有一款可参考、可修改的编程语言架构，帮助学习。

从这个意义上讲，海琛是为学习而生的。

海琛将会在实现基础语法的前提下，提供尽可能多的接口，使用户能够较为轻松地添加新的语言特性。譬如，给海琛添加内存管理机制，又或者增加反射机制等等。这对于更深层的理解相关机制十分有帮助。
